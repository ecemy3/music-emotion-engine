# Experiment Tracking

Bu dosya baseline deneyinin sabitlenmesi için oluşturuldu.

- Sabit split dosyası: `configs/fixed_split_seed42.csv`
- Baseline config: `configs/cnn_baseline.yaml`
- Deney logu: `logs/experiment_log.csv`
- Baseline en iyi model: `models/cnn_baseline_best.pt`
- Baseline son model: `models/cnn_baseline_last.pt`
- Baseline tahminler: `results/cnn_baseline_predictions.csv`
- Baseline metrikler: `results/model_comparison.csv`
